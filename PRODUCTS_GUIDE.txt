QIVORA — ADDING PRODUCTS

1. Open index.html in Notepad/VS Code.
2. Find: const products=[
3. Copy one example product object and change:
   name     = product name
   price    = product price
   rating   = product rating
   category = category, e.g. Women · Dresses
   image    = image path, e.g. images/dress2.jpg
   link     = that product's Meesho commission/tracking link
4. Put photos inside the images folder.
5. Save and upload the updated folder to Netlify.

IMPORTANT: Do not use a normal Meesho URL if you need affiliate commission. Use the eligible commission/tracking link generated by your Meesho creator/affiliate account.
